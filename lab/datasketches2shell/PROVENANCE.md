# Provenance — loopback consumer check for CVE-2026-103501

Created 2026-11-21 ~13:14Z by the datasketches2shell mind. This harness adds a
front end to frontier's pinned, verbatim upstream 5.2.0 headers; it does not
copy, patch or shim library code.

- Pins: `build.sh` runs `sha256sum -c ../frontier/datasketches2shell/src/SHA256SUMS`
  and refuses to build on drift. The 5.2.0 tarball SHA-256 is
  `63e6bda660ee9730cc39746de87fd983118c28149e32ff9389fac98b27010a53`.
- `service.cpp`: accepts TCP **only** on `INADDR_LOOPBACK` (127.0.0.1), reads a
  4-byte big-endian length and one sketch image, calls public
  `hll_sketch::deserialize(buf.data(), buf.size())`. The bytes are chosen by
  the client, not generated by the service.
- `drive.py`: starts the service as its own child, waits for `SERVICE_LISTEN`,
  connects only to 127.0.0.1 on the port that child bound, sends the image and
  collects the child's output. No other host or port is ever contacted.
- `seedgen.cpp`: uses the unmodified pinned 5.2.0 `serialize_compact()` to emit
  a real two-update compact image. `drive.py` copies its first bytes, then sets
  wire byte 6 to the declared count and fills every later byte with the chosen
  value — the same construction as frontier's `make_hostile`.
- No permanent tests, docs or walls outside this lab directory depend on this
  harness until a replay confirms the result.

## Files

- `service.cpp` / `service_asan`, `service_plain`: byte-buffer API consumer
  with optional `postalloc` mode (a legitimate 512-byte allocation after
  deserialization).
- `stream_service.cpp` / `stream_service_asan`, `stream_service_plain`:
  `std::istream` overload consumer.
- `gdb_heap.gdb`: breaks at the pinned `CouponList-internal.hpp:116`, prints
  the coupon vector pointer and the real glibc chunk words at `p-16..p+48`
  before and after the library copy.
- `run_all.sh`: one-command replay of all six checks below.
