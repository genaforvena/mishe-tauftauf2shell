# Redirect candidates past the 289-byte bound (2026-11-26 18:43Z)

Workspace-only measurement with the pinned prebuilt plain vulnerable
`build-vuln-plain/tools/rpm` and `install-vuln/lib/rpm` config, private
`--dbpath`, and the four guarded `/tmp` install names. No external target.
Fixtures were generated by `RPM2SHELL_PAYLOAD_LEN=<len> python3
make-attack.py safe.rpm a<len>.rpm`, then `/opt/` → `/tmp/` for install.

  1152, 1216, 1248, 1280, 1300, 1320, 1344, 1352, 1360 SIGSEGV; 1377

- 1360 SIGSEGV; 1368 SIGABRT; 1376, 1380 SIGSEGV; 1384, 1392, 1400 SIGABRT;
  1416, 1424 SIGSEGV; 1432, 1440, 1441 SIGABRT; 1448 SIGSEGV; 1456, 1472,
  1500, 1552, 1664 SIGABRT.
- Ten repeats: 1201 → 6 SIGSEGV / 4 SIGABRT; 1441 → 10 SIGABRT; 1448 →
  10 SIGABRT. Preserving the chunk-size qword at `buf+0x18` with 0x31, 0xd1
  or 0x21, or all size fields at `buf+0x18+0x10k` up to `0x300`, left 5/5
  SIGABRT at 1441 bytes.

## ASLR layout survey

Ten GDB runs with `set disable-randomization off`, observing the pre-copy
snapshot at `rpmcpioRead()` and GC visits at `lua_resume+0x206` with
`aslr-window/probe.gdb` (GDB only observes; no forced call). Each reported
`WINDOW_VISIT_OFFSETS=52` and `WINDOW_REPORT_DONE=1`. Low-byte redirect
condition: a visited offset `K` holds a canonical pointer `buf+delta` with
`0 < delta < K` and `(delta & ~0xff)+0x10 <= K`.

- `off=0x5a0` (1440), `delta=0x220` (544): 10/10 layouts.
- `off=0x750` (1872), `delta=0x510` (1296): 10/10 layouts.
- `off=0x4b0` (1200), `delta=0x140`; `off=0x690`, `delta=0xe0`;
  `off=0x8f0`, `delta=0x810`: 1/10 layouts each.

The 0x5a0 case would redirect to `buf+0x200` with a zero low byte, fully
inside controlled bytes. At `RPM2SHELL_PAYLOAD_LEN=1441` plain runs abort
before the GC walk. A GDB run with ASLR on logged `Program received signal
SIGABRT, Aborted`, `VISITS=589`, `IN_WINDOW=0`; a second GDB run at the same
length faulted instead, so the exact interception point is layout-dependent
but the plain-process route is 10/10 aborted here.

Conclusion: the old `K <= 0x121` bound did not exclude redirects; the
1441-byte write needed for the stable candidate is stopped by glibc on this
host. No chosen ASLR-stable target, wire path, command or r5.
