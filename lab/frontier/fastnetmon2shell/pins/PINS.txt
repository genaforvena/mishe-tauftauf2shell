SOURCE-BOUND FIX (src/dynamic_binary_buffer.hpp, vulnerable :115)
  BEFORE: if (internal_data_shift + length > maximum_internal_storage_size + 1) {
  AFTER : if (internal_data_shift + length > internal_storage_size) {
  Same +1 removal in append_dynamic_buffer, append_data_as_pointer,
  append_data_as_object_ptr, memcpy_from_ptr, memcpy_from_object_ptr; the fix
  also renames the size field and removes the two low-level memcpy helpers.
  append_byte uses the CORRECT bound in the vulnerable pin (> max - 1), which is
  why the harness fills the valid region with append_byte and overflows via
  append_data_as_pointer.
