## Evidence
`sh run-all.sh` builds vulnerable and fixed harnesses (-O0, ASan and plain),
regenerates both PoCs, runs eight process checks plus a gdb inspection, and
writes logs under `evidence/`. Final clean run 2026-11-24T09:17Z: 9 PASS /
0 FAIL, rc 0, transcript `evidence/run-all.out`. Key logs:
- `evidence/asan-vuln-attack.out`: heap-buffer-overflow, WRITE of size 4 in
  `start_decoder` at `stb_vorbis.c:3889`, 0 bytes after an 8-byte region
  allocated by `setup_malloc` at `stb_vorbis.c:960` from `stb_vorbis.c:3880`.
- `evidence/asan-fixed-attack.out` / `asan-fixed-chosen.out`: rc 0, no report.
- `evidence/gdb-chosen.out`: at the third write (j=0, k=2, `multiplicands[2]`,
  the first OOB float) `val = 0x4b434148` and the stored word is
  `0x4b434148`.

## Negative results / limits
- The first attempt to pass raw IEEE marker bits (`0x4853494d`) as the
  codebook `minimum_value` wrote zeros: stb_vorbis reads that field through
  `float32_unpack()`, not as raw IEEE bits. Corrected by encoding the Vorbis
  float32 form; the earlier failed output is superseded, not hidden.
- Exact total number of OOB floats actually executed before the process dies
  is not measured; issue #1947 argues 31 from its loop bound. UNKNOWN here.
- No network/wire replay, no real consumer build, no pointer/IP/command path.
